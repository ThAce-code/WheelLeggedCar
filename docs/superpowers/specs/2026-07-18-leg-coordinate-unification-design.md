# 腿部坐标统一设计

日期：2026-07-18
目标分支：`codex/balance-fast-mode-spec`

## 1. 背景与问题

当前腿控同时混用了三种含义不同的量：

1. `LH/LHF` 的 `height_mm` 实际是以 55 为中位、通过经验比例换算四个舵机角度的旧标量命令，不是轮心在车体坐标系中的物理 Y 坐标。
2. 旧 `LXY` 使用临时模型坐标，并把 `(0, 55)` 当作参考点。
3. 诊断数据把 `left_x_mm/right_x_mm` 固定写成 0，把 `left_y_mm/right_y_mm` 和 `actual_height_mm` 写成旧标量命令，造成“命令值等于物理位置、物理位置等于实测位置”的错误表述。

物理标定成果已经表明：参考站姿的轮心并不位于 `x = 0`，而是约为：

```text
P0 = (-20.766667 mm, 47.356667 mm)
```

因此，本阶段先统一坐标语义和数据边界，再设计低重心竞速姿态、轮心后移和 LQR 重整定。坐标统一本身不得改变当前常规站立动作，也不得把开环舵机命令描述成实测位置。

## 2. 设计目标

- 全部对外腿部位置统一为一个车体固定的物理坐标系。
- 明确定义参考站姿是物理坐标系中的一个点，而不是坐标原点。
- 将标定模型坐标限制在运动学模块内部。
- 保留现有 `LH/LHF` 的舵机动作，作为旧系统兼容输入。
- 用标定后的正运动学计算命令位置估计，取代伪造的 `x = 0` 和 `y = height`。
- 为以后按毫米定义轮心前后位移提供唯一基准。
- 坐标迁移期间保持现有平衡增益调度和速度限制的数值行为不变。
- 明确左腿已标定、右腿镜像关系尚未独立验证的边界。

## 3. 非目标

本阶段不包含：

- 竞速低重心目标点选择；
- 轮心后移控制、速度到位移的映射或动态轨迹；
- LQR 参数重整定；
- 提高电机速度上限、加速度上限或虚拟前倾角上限；
- 将开环舵机升级为带位置反馈的闭环系统；
- 宣称右腿物理坐标已经通过独立测量验证。

## 4. 坐标域定义

### 4.1 对外物理坐标：`BODY_WHEEL`

所有公开 API、命令语义和遥测中的轮心位置使用 `BODY_WHEEL`：

- 原点：车身上固定的十字圆标记中心；
- 单位：毫米；
- `+X`：车辆前进方向；
- `+Y`：竖直向下；
- 坐标对象：轮心相对于车身固定标记的位置；
- 参考站姿：`P0 = (-20.766667, 47.356667) mm`。

`P0` 是参考姿态点，不是原点。因此参考站姿下 `x != 0` 是正确结果。

以后轮心后移量统一定义为：

```text
rear_shift_mm = P0.x - target.x
```

例如后移 5 mm 时，目标 X 为 `-25.766667 mm`。本阶段只固定该符号和基准，不实现后移控制。

### 4.2 私有模型坐标

标定过程中使用的模型坐标、相似变换矩阵、比例和偏置只允许存在于 `leg_kinematics.c` 及其配置中。其他模块不得直接读取或生成模型坐标，也不得将模型坐标写入遥测。

运动学模块负责：

- `BODY_WHEEL` 物理坐标到模型坐标的变换；
- 模型坐标下的逆运动学；
- 舵机角到模型位置、再到 `BODY_WHEEL` 物理坐标的正运动学；
- 物理工作空间凸包、内缩安全边界和舵机角度限制校验。

### 4.3 旧标量命令域

现有 `LH/LHF` 输入保留，但其值明确改称“旧站姿标量单位”，不再带 `_mm` 后缀，也不再称为物理高度。

兼容阶段的旧标量只用于：

- 保持原有四舵机角度生成行为；
- 保持现有增益调度、速度限制和模式切换的数值行为；
- 支持已有常规站立与测试流程。

旧标量不得直接写入物理 X/Y 字段。物理位置必须由最终舵机命令经过标定正运动学获得。

## 5. 统一后的数据契约

### 5.1 物理位置的状态类型

腿部诊断应公开左右腿各自的 `BODY_WHEEL` 命令位置估计，至少包含：

- `x_mm`；
- `y_mm`；
- `valid`：正运动学、舵机范围和标定状态是否有效；
- `source`：左腿实测标定或右腿镜像假设；
- `kind`：明确为 `command_estimate`，不能命名为 `actual` 或 `measured`。

建议在类型层面将 X/Y 和有效性组织为一个物理姿态结构，避免不同模块只更新其中一个字段。

### 5.2 目标、参考与命令估计

物理位置需要区分三种角色：

- `reference_pose_body_mm`：标定参考点 `P0`；
- `target_pose_body_mm`：物理 XY 命令的目标点；
- `command_estimate_pose_body_mm`：最终舵机角对应的正运动学估计。

`LH/LHF` 没有直接的物理目标点，因此只保留旧标量目标，并发布最终舵机命令对应的 `command_estimate_pose_body_mm`。不得用旧标量伪造 `target_pose_body_mm`。

### 5.3 开环语义

舵机系统没有轮心位置传感器。正运动学结果只能说明“控制器命令这些舵机角时，标定模型预计轮心在哪里”。因此：

- 删除或替换误导性的 `actual_height_mm`；
- 物理位置字段统一使用 `command_estimate`；
- 遥测、日志和文档不得使用“实测轮心位置”描述该值；
- 硬件标尺或视觉测量结果只能作为离线标定/验收数据，不能冒充运行时反馈。

## 6. 运行时数据流

### 6.1 `LH/LHF` 兼容路径

```text
旧站姿标量命令
    -> 现有经验角度映射与轨迹规划
    -> 四舵机最终逻辑角
    -> 标定脉宽修正并输出 PWM
    -> 标定正运动学
    -> BODY_WHEEL 命令位置估计
```

该路径不使用“物理坐标 -> IK -> 舵机角”的往返转换，以免坐标迁移改变当前站立动作。

### 6.2 `LIKREF/LXY` 物理路径

```text
BODY_WHEEL 物理目标
    -> 物理凸包与 2 mm 内缩边界校验
    -> 物理到模型坐标变换
    -> 逆运动学与舵机范围校验
    -> 四舵机轨迹规划
    -> 标定脉宽修正并输出 PWM
    -> 正运动学命令位置估计
```

`LIKREF` 使用 `P0`。`LXY` 接收绝对 `BODY_WHEEL` 毫米坐标。旧临时坐标命令 `LXY,0,55` 必须被拒绝，不能继续解释为参考站姿。

## 7. 标定参数和来源

从 `c07702a` 选择性迁移以下物理标定成果：

- 物理参考点 `P0 = (-20.766667, 47.356667) mm`；
- 物理坐标与模型坐标的相似变换；
- 正/逆运动学的物理坐标接口；
- 八顶点物理工作空间凸包与 2 mm 内缩边界；
- 舵机 0 的 `-11.111111 us` 脉宽修正；
- 物理 IK 静态与数值回归检查。

只迁移腿部物理坐标所需的文件和测试，不引入该提交后续的相机、锥桶或其他运行时功能。

右腿目前沿用镜像几何假设，但没有独立物理测量验证。因此：

- 右腿 `source` 必须标记为镜像假设；
- 右腿坐标可用于静态诊断和低风险台架校验；
- 在右腿独立验证前，不允许仅凭该坐标启用高速动态轮心后移。

## 8. 平衡控制兼容边界

现有平衡控制和底盘控制使用 `height_norm/height_ref_mm` 进行增益调度与速度限制。这些值来源于旧站姿标量，并非经验证的物理轮心 Y 或整车重心高度。

本阶段将其明确改名为旧站姿调度量，例如：

- `legacy_stance_ref_units`；
- `legacy_stance_norm`。

迁移时要求：

- 原有输入到增益、速度限制的数值映射保持一致；
- 不以物理 Y 直接替换旧调度量；
- 不因字段改名改变 LQR、速度环或快速模式行为；
- 后续低重心竞速方案必须基于统一后的物理姿态重新采集数据并评估 LQR。

这样可将“坐标语义修复”和“控制器重新整定”分开验收，出现问题时也能明确归因。

## 9. 遥测迁移

遥测需要升级字段语义或帧版本，至少做到：

- 保留必要的旧站姿标量诊断，但字段名使用 `units`，不使用 `mm`；
- 发布左、右轮心的物理 X/Y 命令位置估计；
- 发布物理位置的有效性与来源；
- 删除或废弃 `actual_height_mm`；
- 不再把左、右 X 固定为 0；
- 不再把旧站姿标量复制为物理 Y；
- 同步更新采集脚本、CSV 列名和静态测试，避免新旧日志被混读。

如果受现有遥测通道数量限制，应优先保证左右 X/Y 和有效性可追踪；旧字段可通过明确版本的兼容通道暂留，但不能继续使用错误单位。

## 10. 安全与失败行为

- 物理目标超出内缩凸包时，命令拒绝，不投影到边界、不静默截断。
- 逆运动学无解、舵机角越界或变换参数无效时，保持现有安全目标并上报诊断。
- 正运动学命令估计无效时，设置 `valid = 0`，不得回退为 `x = 0, y = legacy_value`。
- 物理标定参数缺失或不一致时，禁用 `LXY/LIKREF` 物理命令；旧 `LH/LHF` 兼容站立路径仍遵循现有安全门控。
- 坐标迁移不放宽电机、舵机、模式切换或转场期间的现有安全限制。

## 11. 组件边界

预计实施涉及：

- `leg_config.c/.h`：物理参考点、变换、凸包与标定来源；
- `leg_kinematics.c/.h`：唯一的物理/模型转换、正逆运动学和工作空间校验；
- `actuator_servo.c`、`app_config.h`：标定脉宽修正；
- `control_leg.c`：区分旧标量兼容路径和物理 XY 路径，发布正运动学估计；
- `app_types.h`：统一后的物理姿态与旧调度量字段；
- `control_balance.c`、`control_chassis.c`：只做兼容字段迁移，保持调度数值不变；
- `telemetry.c` 与采集脚本：更新帧契约和 CSV 列名；
- `tools/` 下相关静态、数值和遥测测试：覆盖新语义和回归行为。

为了避免 `control_leg.c` 继续承担坐标变换，所有变换和工作空间判断必须留在运动学模块。后续轮心位移策略也应作为独立控制层使用物理姿态接口，而不是直接操作舵机角或模型坐标。

## 12. 验收标准

### 12.1 静态与数值验收

- 参考命令和 `LIKREF` 使用并报告 `P0`，不再报告 `(0,55)`。
- `LXY,0,55` 被工作空间校验拒绝。
- `LH=55` 保持现有四舵机 90 度逻辑动作；其正运动学命令估计在标定误差范围内接近 `P0`。
- 所有公开物理坐标来自运动学模块，代码中不存在把物理 X 固定为 0、把旧标量直接赋给物理 Y 的路径。
- 工作空间使用凸包和 2 mm 内缩，不退化为独立 X/Y 极值矩形。
- 舵机 0 脉宽修正和舵机角限制通过回归测试。
- 左腿来源标记为实测标定，右腿来源标记为镜像假设。
- 旧平衡增益和速度限制对相同旧站姿输入产生与迁移前相同的数值结果。
- 当前舵机频率、S7 轨迹、低通、腿控、平衡和调度相关静态测试继续通过。

### 12.2 构建与硬件验收

- 受影响的 CM7_0 IAR 工程无新增错误和警告。
- 电机保持禁用时，执行 `LIKREF`，核对遥测参考点和四舵机输出。
- 用标尺/视觉重新核对左轮心参考点，目标与测量误差按 X/Y 分量记录。
- 独立测量右轮心参考点和至少两个非参考点，确认或修正镜像关系。
- 只有左右腿均通过物理坐标验收后，才进入低重心与动态轮心后移设计。

## 13. 实施顺序

1. 迁移物理标定配置、脉宽修正和物理正逆运动学。
2. 建立统一物理姿态类型和来源/有效性字段。
3. 改造 `LIKREF/LXY` 为绝对 `BODY_WHEEL` 物理命令。
4. 保持 `LH/LHF` 角度行为，增加最终舵机角的物理正运动学估计。
5. 删除伪造的物理位置与 `actual` 命名。
6. 迁移旧平衡调度字段名称，并用回归测试证明数值行为不变。
7. 更新遥测、采集脚本、CSV 契约和全部相关测试。
8. 完成 IAR 构建和电机禁用的硬件坐标验收。

完成上述步骤后，低重心竞速姿态和轮心后移将直接使用统一的 `BODY_WHEEL` 毫米坐标设计，不再依赖“腿高等于轮心 Y”或“参考点 X 等于 0”的假设。
